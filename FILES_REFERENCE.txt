DATABASE SCHEMA
═════════════════════════════════════════════════════════════════════════════

clients (Master database)
  ├─ id (PK)
  ├─ client_id (UNIQUE)
  ├─ surname (INDEXED, FULLTEXT) [MIN 4 CHARS]
  ├─ full_name (FULLTEXT)
  ├─ phone
  ├─ email
  ├─ address
  ├─ notes
  └─ timestamps

queue_entries (Current queue)
  ├─ id (PK)
  ├─ client_id (FK → clients)
  ├─ counter_number (INDEXED)
  ├─ purpose
  ├─ status (INDEXED)
  └─ timestamps

call_history (Audit trail)
  ├─ id (PK)
  ├─ client_id (FK → clients)
  ├─ counter_number (INDEXED)
  ├─ purpose
  ├─ service_duration
  └─ timestamps

API ENDPOINTS (6 NEW)
═════════════════════════════════════════════════════════════════════════════

GET api.php?action=search_clients&surname=SURNAME
  └─ Search clients by surname (min 4 chars)

POST api.php?action=create_client
  └─ Create new client
  Body: { surname, full_name, phone, email }

POST api.php?action=assign_client
  └─ Assign client to counter queue
  Body: { client_id, counter, purpose }

GET api.php?action=counter_queue&counter=1
  └─ Get current queue for counter

POST api.php?action=call_next_client
  └─ Call next client from queue
  Body: { counter }

POST api.php?action=complete_service
  └─ Mark service as complete
  Body: { entry_id }
